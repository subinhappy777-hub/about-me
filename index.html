나의 프로젝트 경험

🌱 1. 끈기와 책임감

어려운 문제도 끝까지 해결하려는 자세

음질과 연산 효율 사이에서 최적의 균형을 찾다

1. 문제 상황
Diffusion-TTS 보코더는 고품질의 음성을 생성할 수 있지만, 많은 연산량과 긴 합성 시간이 필요하다는 한계가 있었습니다. 이를 개선하기 위해서는 단순히 모델의 크기를 줄이는 것이 아니라, 음질을 유지하면서 연산 효율을 높이는 방법이 필요했습니다.

2. 해결 과정
이러한 문제를 해결하기 위해 Depthwise Separable LVC 기반의 모델을 구현하고 신경망 경량화 기법을 적용했습니다. 모델의 연산량을 줄이는 과정에서도 음성 품질이 저하되지 않도록 두 요소의 균형을 고려하며 최적화 연구를 진행했습니다.

3. 결과
그 결과, 기존 모델의 음질을 유지하면서 연산량과 음성 합성 시간을 줄일 수 있었습니다. 이를 통해 음성 품질과 연산 효율을 함께 고려한 모델 최적화의 가능성을 확인했습니다.

4. 아쉬운 점
연산량과 합성 시간을 줄이는 성과를 얻었지만, 모델의 구조적 변화가 음질과 합성 속도에 각각 어떤 영향을 미치는지 충분히 분석하지 못한 점이 아쉬웠습니다. 연구를 마친 후에도 결과를 다시 돌아보며, 경량화 기법의 적용 범위에 따른 성능 차이를 더욱 구체적으로 검증할 필요가 있다고 생각했습니다.

5. 앞으로의 개선 방향
다시 연구를 진행한다면 경량화 기법의 적용 범위와 모델 구조를 다양하게 변경하고, 동일한 실험 환경에서 연산량·합성 시간·음질을 비교하고 싶습니다. 이를 통해 단순히 성능을 개선하는 데 그치지 않고, 어떤 변화가 성능 향상에 기여했는지 근거를 가지고 설명할 수 있는 연구를 이어가고 싶습니다.

🔍 2. 문제 분석과 개선

문제의 원인을 찾고 개선 방법을 고민하는 자세

데이터의 불일치를 해결하고, 더 나은 예측 방법을 고민하다

1. 문제 상황
태양광 발전량 예측 모델을 개발하는 과정에서 기상 데이터와 발전소 데이터의 시간 간격이 일치하지 않는 문제가 발생했습니다. 예측 모델에는 1시간 단위의 데이터가 필요했지만, 확보한 데이터는 약 2시간 간격으로 구성되어 있어 그대로 활용하기 어려웠습니다.

2. 해결 과정
데이터의 시간 간격을 맞추기 위해 앞뒤 시점의 평균값을 활용하는 선형 보간법을 적용했습니다. 이를 통해 중간 시점의 값을 생성하여 데이터를 1시간 단위로 구성하고, 전처리한 데이터를 기반으로 앙상블 예측 모델을 개발했습니다. 또한 Flask를 활용해 예측 결과를 웹페이지에서 확인할 수 있도록 구현했습니다.

3. 결과
시간 간격이 일치하지 않는 데이터를 예측 모델에 활용할 수 있는 형태로 구성하고, 태양광 발전량 예측 시스템을 구현했습니다. 이 과정에서 모델을 개발하는 것뿐만 아니라, 데이터의 문제를 파악하고 해결하는 과정이 전체 시스템 구현에 중요하다는 것을 확인했습니다.

4. 아쉬운 점
데이터의 불일치 문제는 해결했지만, 당시에는 시간적 제약으로 선형 보간법 외에 다양한 전처리 방법을 비교하지 못했습니다. 프로젝트를 마친 후에는 앞뒤 값의 평균으로 생성한 데이터가 실제 발전량의 변화 특성을 얼마나 반영할 수 있는지, 다른 방법을 사용했다면 예측 결과가 달라졌을지에 대한 의문이 남았습니다.

5. 앞으로의 개선 방향
다시 프로젝트를 진행한다면 선형 보간법뿐만 아니라 다양한 시계열 보간 방법을 적용하고, 각 방법이 예측 성능에 미치는 영향을 비교하고 싶습니다. 특히 실제 관측값을 일부 제외한 뒤 보간 결과와 비교하여 데이터 복원 오차를 확인하고, 전처리 과정에서 내린 선택이 최종 예측 결과에 어떤 영향을 미쳤는지 검증하고 싶습니다.

🤖 3. AI 기술에 대한 관심

기술을 실제 생활의 문제 해결에 활용하려는 자세

AI 기술을 실제 생활의 문제 해결로 연결하다

1. 문제 상황
시각장애인은 보행 중 주변 장애물의 위치와 거리를 파악하는 데 어려움을 겪을 수 있습니다. 이러한 문제를 해결하기 위해서는 장애물의 존재를 탐지하는 것뿐만 아니라, 장애물과의 거리 및 위험 수준을 함께 파악할 수 있는 기술이 필요하다고 생각했습니다.

2. 해결 과정
YOLOv8 객체 탐지 모델과 단안 깊이 추정(Monocular Depth Estimation) 기술을 결합하여 장애물의 위치와 거리를 추정했습니다. 이후 추정한 거리 정보를 활용해 위험 수준을 구분하고, 이를 시각화하여 주변 환경의 위험 요소를 확인할 수 있도록 구현했습니다.

3. 결과
객체 탐지와 거리 추정 기술을 결합하여 장애물의 위치뿐만 아니라 거리와 위험 수준을 함께 확인할 수 있는 기능을 구현했습니다. 이를 통해 서로 다른 AI 기술을 하나의 시스템으로 연결하고, 보행 안전이라는 실제 문제에 활용할 수 있는 가능성을 확인했습니다.

4. 아쉬운 점
장애물의 거리와 위험 수준을 시각화하는 기능을 구현했지만, 프로젝트를 돌아보면서 실제 시각장애인이 이러한 정보를 어떻게 전달받고 활용할 수 있을지 더 고민할 필요가 있다고 생각했습니다. 또한 조명이나 카메라 움직임 등 실제 보행 환경의 변화에 따라 탐지 및 거리 추정 결과가 얼마나 안정적으로 유지되는지도 추가로 검증해 보고 싶었습니다.

5. 앞으로의 개선 방향
다시 프로젝트를 진행한다면 다양한 보행 환경에서 객체 탐지와 거리 추정의 정확도를 검증하고, 발생하는 오류를 분석하여 시스템의 안정성을 높이고 싶습니다. 나아가 음성이나 진동을 통해 위험 정보를 전달하는 기능을 추가하고, 실제 사용자가 위험 상황을 인지하는 데 얼마나 도움이 되는지 확인하며 시스템을 발전시키고 싶습니다.
