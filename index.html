Diffusion-TTS 보코더 최적화 연구

1. 문제 상황
Diffusion-TTS 보코더는 높은 음질을 제공하지만, 많은 연산량과 긴 합성 시간이 필요하다는 한계가 있었습니다.

2. 해결 과정
Depthwise Separable LVC 기반의 경량화 모델을 구현하여 음질을 유지하면서 연산 효율을 높이고자 했습니다.

3. 결과
기존 음질을 유지하면서 연산량과 음성 합성 시간을 줄이는 성과를 얻었습니다.

4. 아쉬운 점
모델의 구조적 변화가 음질과 합성 속도에 미치는 영향을 더욱 세밀하게 분석하지 못한 점이 아쉬웠습니다.

5. 앞으로의 개선 방향
다양한 모델 구조와 경량화 기법을 비교하여 성능 개선의 원인을 분석하고 최적의 구조를 찾고 싶습니다.

    태양광 발전량 예측 프로젝트

    1. 문제 상황
    예측 모델에는 1시간 단위의 데이터가 필요했지만, 확보한 데이터는 2시간 간격으로 구성되어 있었습니다.

    2. 해결 과정
    앞뒤 시점의 평균값을 활용한 선형 보간법으로 데이터를 1시간 단위로 구성했습니다.

    3. 결과
    전처리한 데이터를 기반으로 앙상블 예측 모델을 개발하고, Flask로 예측 결과를 확인하는 웹페이지를 구현했습니다.

    4. 아쉬운 점
    시간적 제약으로 다양한 보간 방법을 비교하고 예측 성능에 미치는 영향을 검증하지 못했습니다.

    5. 앞으로의 개선 방향
    여러 보간 기법을 적용하고 예측 성능을 비교하여 데이터 특성에 적합한 전처리 방법을 찾고 싶습니다.

      시각장애인 보행 안전 프로젝트

      1. 문제 상황
      시각장애인의 안전한 보행을 지원하기 위해 주변 장애물의 거리와 위험도를 파악할 기술이 필요했습니다.

      2. 해결 과정

      3. 결과
      탐지된 장애물과의 거리 및 위험 수준을 시각화하여 보행 환경의 위험 요소를 확인할 수 있도록 구현했습니다.

      4. 아쉬운 점
      실제 보행 환경에서 조명 변화나 카메라 움직임에 따른 탐지 및 거리 추정의 안정성을 더 검증해 보고 싶었습니다.

      5. 앞으로의 개선 방향
