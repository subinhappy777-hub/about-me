## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| **상단 소개 영역** | 제목과 페이지 목적을 설명하는 소개 문구 |
| **왼쪽 프로필 영역** | 이름, 인사말, 관심사, 목표를 정리해 표시 (스크롤 시 고정) |
| **오른쪽 프로젝트 영역** | 3개의 강점·프로젝트 카드 |
| **근거 보기 토글** | 버튼 클릭 시 관련 논문 링크가 펼쳐지는 아코디언 UI |
| **논문 링크** | koreascience.kr, DBpia 논문으로 새 창 이동 |
| **GitHub 푸터** | 하단에 GitHub 저장소 주소 표시 |
| **반응형 디자인** | 768px 이하에서 1단 레이아웃으로 자동 전환 |

## 🛠️ 사용 기술

| 구분 | 내용 |
|------|------|
| **HTML5** | 시맨틱 마크업 (`header`, `main`, `section`, `footer`) |
| **CSS3** | CSS 변수, Grid, Flexbox, `backdrop-filter`, 미디어 쿼리 |
| **JavaScript (Vanilla)** | 아코디언 토글, `aria-expanded` 접근성 처리 |
| **디자인** | 어두운 마블링 그라데이션 배경 + 반투명 유리 패널 |

> 별도의 프레임워크나 라이브러리 없이 **순수 HTML/CSS/JS**로만 구현했습니다.
